# OBSIDIANA — Toolchain

> The Dockerfile at the project root is the source of truth for tool
> versions. Host-native and devcontainer installs must match. If you
> find a drift, fix the Dockerfile first.

## Pinned versions

| Tool            | Version        | Why                                                |
| --------------- | -------------- | -------------------------------------------------- |
| Rust (stable)   | 1.79           | Tauri 2 requires Rust ≥ 1.75; 1.79 is current.     |
| Node            | 20 LTS (20.18) | Tauri 2 requires Node ≥ 18; 20 LTS is current.     |
| pnpm            | 9.12.1         | Current LTS line; matches `packageManager` field.  |
| `tauri-cli`     | ^2.0           | Tauri 2 CLI, installed via `cargo install`.        |

The Tauri Rust crates (`tauri`, `tauri-build`) are pinned to `^2.0` in
`src-tauri/Cargo.toml`. Do not bump them without an ADR in
`docs/architecture.md`.

## Workflow A — Container (recommended for the AI agent and CI)

Requires only Docker on the host.

```sh
docker compose build dev
docker compose run --rm dev pnpm install
docker compose run --rm dev pnpm vitest run
docker compose run --rm dev cargo test --manifest-path src-tauri/Cargo.toml
docker compose run --rm dev pnpm tauri build
```

The `dev` service mounts the project at `/workspace` and persists
Cargo + pnpm caches across runs via named volumes (`cargo-target`,
`cargo-target-src`, `pnpm-store`).

To open a shell:

```sh
docker compose run --rm dev bash
```

`pnpm tauri dev` will NOT work inside the container — the WebView needs
a display. Use workflow B or C for iterative GUI development.

## Workflow B — Devcontainer (VS Code)

1. Install the **Dev Containers** extension in VS Code.
2. Open the project folder in VS Code.
3. Run the command: `Dev Containers: Reopen in Container`.
4. VS Code builds the same `Dockerfile` and attaches to the `dev` service.

X11 / Wayland forwarding is finicky. For `pnpm tauri dev` with a real
WebView, prefer workflow C on the host.

## Workflow C — Host-native (best for `pnpm tauri dev`)

Pick your OS below. Every command assumes a fresh shell with no Node /
Rust / pnpm already installed.

### Linux (Debian / Ubuntu)

```sh
sudo apt update
sudo apt install -y build-essential curl wget file git libssl-dev \
    libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev \
    libwebkit2gtk-4.1-dev patchelf
```

Rust (via rustup):
```sh
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source "$HOME/.cargo/env"
rustup component add rustfmt clippy
```

Node 20 LTS (via NodeSource):
```sh
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
```

pnpm (via corepack, ships with Node 20):
```sh
corepack enable
corepack prepare pnpm@9.12.1 --activate
```

Tauri CLI:
```sh
cargo install tauri-cli --version "^2.0" --locked
```

Then, from the project root:
```sh
pnpm install
pnpm vitest run
cargo test --manifest-path src-tauri/Cargo.toml
pnpm tauri dev
```

### macOS (Apple Silicon or Intel)

Xcode Command Line Tools:
```sh
xcode-select --install
```

Rust (via rustup):
```sh
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source "$HOME/.cargo/env"
rustup component add rustfmt clippy
```

Node 20 LTS (via Homebrew):
```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install node@20
brew link --force node@20
```

pnpm:
```sh
corepack enable
corepack prepare pnpm@9.12.1 --activate
```

Tauri CLI:
```sh
cargo install tauri-cli --version "^2.0" --locked
```

For `.icns` icon support, no extra step is needed — Tauri ships a
bundled `iconutil` workflow. Real macOS bundles also need a
`src-tauri/icons/icon.icns` file (not generated by the scaffold; add
during a polish pass).

### Windows (10/11, x64)

Install [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)
with the "Desktop development with C++" workload.

Rust (via rustup, MSVC toolchain):
```sh
rustup-init.exe -y
rustup default stable-x86_64-pc-windows-msvc
rustup component add rustfmt clippy
```

Node 20 LTS (via the official `.msi`):
- Download and run: <https://nodejs.org/dist/v20.18.0/node-v20.18.0-x64.msi>

pnpm:
```sh
corepack enable
corepack prepare pnpm@9.12.1 --activate
```

Tauri CLI:
```sh
cargo install tauri-cli --version "^2.0" --locked
```

WebView2 runtime is pre-installed on Windows 10/11 in 2022+; if missing,
install from <https://developer.microsoft.com/microsoft-edge/webview2/>.

## Verifying the install

After installing on the host, run from the project root:

```sh
node --version       # v20.x
pnpm --version       # 9.12.1
rustc --version      # 1.79.x
cargo --version      # 1.79.x
tauri --version      # tauri-cli 2.x
```

If any of these are missing or wrong, fix the toolchain before
debugging OBSIDIANA. 90% of "the app won't start" reports are a
toolchain version mismatch.

## Adding new host dependencies

If a future Rust crate needs a system library (e.g. `libsqlite3-dev`),
update the Dockerfile's `apt-get install` line, the devcontainer
inherits automatically, and append the apt command to the **Linux**
section above. Mirror the same change on macOS (brew) and Windows
(vcpkg / NuGet) so all three workflows stay in sync.
